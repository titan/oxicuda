### oxicuda-tn TODO

Tensor Networks for OxiCUDA — a pure Rust toolkit for Matrix Product States (MPS),
Matrix Product Operators (MPO), DMRG ground-state search, time-evolving block
decimation (TEBD), 2D PEPS, Tensor-Train (TT), Tucker (HOSVD / HOOI), and CP / PARAFAC
decompositions. Part of [OxiCUDA](https://github.com/cool-japan/oxicuda) (Vol.50).

(C) 2026 COOLJAPAN OU (Team KitaSan)

## Implementation Status

**Actual: 5,928 lines / 28,138 SLoC (73 files)** — implements a complete tensor-network
stack in pure Rust with no external linear-algebra dependencies. SVD, Lanczos, and
eigendecomposition are written from scratch (one-sided Jacobi SVD, Gram-Schmidt
Lanczos, symmetric tridiagonal Jacobi). Includes 7 PTX kernels × 6 SM versions.

## Notes

- All linear algebra is implemented from scratch: one-sided Jacobi SVD (sign-correct
  Givens rotations), Gram-Schmidt-orthogonalised Lanczos, symmetric tridiagonal Jacobi
  eigensolver. This avoids any LAPACK / OpenBLAS dependency.
- PTX kernels use string concatenation rather than `format!` to keep register names
  stable across SM versions and to satisfy the `clippy::format_push_string` lint.
- `MpsTensor` stores data row-major in the order `[D_l, d, D_r]` so that the
  left-canonical form `M^T · M = I` is a straightforward reshape + matrix product.
- DMRG uses two-site updates (better at avoiding local minima than single-site DMRG)
  with explicit left / right environment caching across sweeps.
